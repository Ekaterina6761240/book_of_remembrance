# MultimediaPro — WP-CLI installer

Этот скрипт автоматизирует первичную настройку сайта:
- язык/локаль ru_RU, часовой пояс, форматы дат/времени;
- ЧПУ (`/%postname%/`) и flush rewrite;
- активация базовых плагинов (если установлены): Russia Pack, Classic Editor Plus, Carbon Fields Bridge;
- создание страниц «Главная» и «Блог», назначение их как главной и страницы записей.

## Требования
- Установленный сайт MultimediaPro (MultimediaPro), доступный для WP-CLI.
- Доступ к консоли на сервере.

## Запуск
```bash
bash tools/installer.sh --path=/var/www/html
```
Параметр `--path` укажите на корень сайта (там, где `wp-config.php`). Если WP-CLI уже в нужной директории, можно без параметра.

## Примечания
- Скрипт безопасен при повторном запуске: шаги idempotent, ошибки активации плагинов игнорируются.
